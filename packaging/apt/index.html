pbs-sync-auth APT repository

Signed APT repository for the pbs-sync-auth client on a Proxmox Backup Server (Debian 13 / amd64). Add it once, then updates arrive via apt upgrade.

Setup on the PBS

On a PBS you operate as root, so these commands use no sudo.

curl -fsSL https://ftaeger.github.io/pbs-sync-auth/pubkey.asc \
  | gpg --dearmor > /usr/share/keyrings/pbs-sync-auth.gpg

echo "deb [signed-by=/usr/share/keyrings/pbs-sync-auth.gpg] \
  https://ftaeger.github.io/pbs-sync-auth stable main" \
  > /etc/apt/sources.list.d/pbs-sync-auth.list

apt update
apt install pbs-sync-auth-client

After installing, place the shared secret and enable the service as described in the project README.
